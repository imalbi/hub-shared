# Lavoro

- `applications.ts` computes effective expiry without changing saved status. For applications with interviews, use the latest `scheduledAt` (number in client rows, Date in database rows); `links.byApplications` selects dates for the same rule.
- `candidature-view.ts` owns phase lists and counts; `stats.ts` counts replies from interviews, offers and rejections, never from linked mail. Private UI copy stays in `copy.ts`.
- `openCandidatura` and `candidaturaPrompt` read `ctx.config.mcp.client` and pass opaque `postingId(key)` (resolved by `lavoro.posting`) with zero title words. `candidaturaClientArgs` runs Claude with `--permission-mode default --strict-mcp-config --mcp-config <hub-only> --disallowedTools ...` and Codex with `--sandbox workspace-write --ask-for-approval on-request -c mcp_servers={hub=...}` (only Hub MCP enabled). Codex refuses to launch or copy if `skills/candidatura/SKILL.md` is missing.
- `importRead` is `loopbackProcedure` + `pageOnly: true` (never exposed to MCP agents). `public-host.ts` (`isPrivateOrLoopbackIp`, `isPublicHostname`) splits IPv4 and IPv6 `net.BlockList` checks so mapped/compatible/NAT64/SIIT/6to4/site-local literals are blocked without blocking public IPv4; live `fetchPage` uses `pinnedRequest` with 1-hop same-host redirect check; `importSave` and `edit` require `http(s)` URLs (`assertHttpUrl`).
- Agent guards (`server.ts`): `edit`, `importApplications`, `setApplication` (with `notes` or `appliedAt`), and `rules.{create,update,setEnabled,include}` fail with `FORBIDDEN` (`forbidAgent`) for MCP agents; agent reads (`list`, `posting`, `searchRecords.*`, `links.*`) redact mail-proposal rejection `reason` and interview `label` while keeping owner-written `reason` and linked `mail[].subject` (Plan 73 exception).
- `mail-check.ts`: `canAutoLinkSender` requires a non-freemail sender domain (`isFreeMailDomain`) matching a confirmed `application_address` or exact company domain token (`companyDomainEvidence`, no substring fallback); model links wait to insert `application_address` until owner confirmation in `mailCheck.accept`; `ui-mail-proposals.tsx` and `ui-mail-todos.tsx` render mail text/URLs as plain spans with sender address and zero `<a>` links.
- Scrapers & LaTeX: `bounded-fetch.ts` caps bodies at 4 MiB and follows at most 5 same-site redirects with `redirect: 'manual'` across all 9 scrapers and `bando.ts`; `config.ts` validates public employer hosts (`isPublicHostname`) and marks terminal/host/URL/LinkedIn rate fields `manual: true`; `collect.ts` escapes markup in notification bodies and passes `--` before positional args; `skills/candidatura/SKILL.md` uses `skills/tools/tex-check.ts` and `openin_any=p openout_any=p pdflatex -no-shell-escape`.
- `widget-summary.ts` (`summarizeLavoro` backing `lavoro.summary`) reuses `sortJobs(..., 'opinion')`, `candidature-view.ts` (`segmentCounts`), and `applications.ts` (`effectiveApplicationStatus`/`isActive` so interviews on closed/expired applications never count in `interviewsThisWeek`). Keep `formatCollectionLabel` in `format.ts` (never import `widget-summary.ts` from browser components, or Vite pulls `opinion-prompt.ts`'s `node:timers/promises` import).
- `ui-widget.tsx` owns `LavoroWidget` (`small`/`medium`/`large`, widget label `copy.widget.title` `'Lavoro'` distinct from `copy.zone_title` `'Ricerca lavoro'`) and `useLavoroSummary()` (shared with `useLavoroToday` in `ui.tsx`, invalidating `['lavoro', 'summary']` on `onState` transitions with no `refetchInterval`); navigate using `useNavigate` from `../../apps/web/src/lib/zone-search.ts` (`vite.config.ts` does not alias `@tanstack/react-router` for private module folders).
- `stable.ts` + `score.ts`: `stableReasons` triggers only on `company` or `site` (never `"tempo indeterminato"` / `contract`, which is a `weights.description` weight); the Stabile floor requires a positive `stable.titleWeights` hit, `score >= 0`, and `yearsPenalty === 0`; `stable.bonus` is added to `bonus`/`total` (`stabile:+N (azienda)`) only after clearing the floor, exclusions, and protected categories. `near-miss.ts` admits Stabile floor misses based on `minScore` even when dev `titleScore` is `0`.
- `opinion-prompt.ts` (`promptVersion = 9`): splits evaluation into mutually exclusive `Caso A` (entry-level/apprenticeship/concorsi on diploma without mandatory prior experience) and `Caso B` (specialist roles requiring prior experience).
- `server.ts`: `dismissNearMiss` and `dismissAllNearMisses` are owner-only (`forbidAgent(ctx)`) and record dismissed keys in `purged_jobs` so collections never re-add them. `refetchDescription` is owner-only (`agentOrLoopbackProcedure` + `forbidAgent`, no `.meta`), requires a registered `source.describe`, pins public HTTP targets and serializes manual requests with the configured LinkedIn interval. It rescores in place without replacing application/opinion rows. The UI offers `"Riprova scaricamento"` only for empty, incomplete postings with a supported source; a stale missing flag never hides stored text.
- `workday.ts` & `synergie.ts`: Workday builds host-aware public URLs (`.myworkdaysite.com` uses `/recruiting/<tenant>/<site><externalPath>`, `.myworkdayjobs.com` uses `/<site><externalPath>`), reads `total` from page 1 only, supports per-employer `searchText`, and merges `additionalLocations`; Synergie bootstraps public Algolia config from `BOOTSTRAP_URL`, queries `region` + `archived:0` facets without detail GETs, cleans multi-section HTML via `cleanHtml`, and skips `Gruppo Iren` / `IRETI` / `IRENfutura` reposts already collected by `iren.ts`.
- Pagination controls archival: `synergie.ts` must reach `nbPages` even across filtered or duplicate pages; `workday.ts` retains each page before requesting the next, so later failures preserve partial results and stay incomplete.

- Catalog portability: tests must be independent of sibling modules; `server.test.ts` declares its manual-field fixture inline. Iren cards without a town use `SearchInput.location`; the Parere prompt takes qualifications only from the supplied profile.

- `e2e/root/lavoro/server.ts` seeds applications that earlier specs can mutate; Candidature checks independent of status use `?candidature=all`, since the default pending segment may no longer contain the seeded row.

- `config.ts`: source scopes stay under `search.<site>` and are required when enabled globally or by a query override; personal geographic/employer defaults are forbidden. `harness.ts` supplies explicit invented source scopes for fixtures.

- `ingest.ts`: incomplete non-blacklisted rows bypass the known-URL cache on rediscovery. Repair them in place only after recovering text (including card text); failed retries preserve the entire saved row and related state. Complete rows remain known. A source missing flag may indicate a partial abstract (Iren/Oracle), so text alone must not clear it.
